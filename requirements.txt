# Aircrack-ng Industrial Audit Tool (Termux V2.0)
#
# Python packages:
# This script uses only the standard library (subprocess, os, sys, time).
# No pip packages are required, so "pip install -r requirements.txt" installs nothing.
#
# System dependencies (install with your system's package manager, not pip):
#
# Kali Linux:
#   sudo apt update && sudo apt install -y aircrack-ng python3
#
# Termux (Android):
#   pkg update -y && pkg install -y aircrack-ng python
#
# Windows:
#   Install Python 3 from python.org (check "Add Python to PATH").
#   Download aircrack-ng from https://www.aircrack-ng.org/downloads.html
#   and add the folder with aircrack-ng.exe to PATH.
